What the model receives

  • Aggregated facts and tool results: model, counts, capacity values, assumptions and your messages.
  • Never the Tech Support File, host names, IP addresses, serial numbers, user names or object and rule names. Every message is also passed through a filter that masks addresses, host names, e-mail addresses and serial-like numbers.
  • The gateway's AI security profile inspects the traffic. If it blocks a request, the agent stops and says so. It does not retry or rephrase.
  • Every figure in a verdict is checked against the tool results before it is shown as verified.
