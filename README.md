# TSF Sizing Agent

A web tool that runs in a Docker container. Upload a PAN-OS Tech Support File (TSF) and it recommends a replacement firewall model from the current portfolio, with the reasoning written out.

Status: portfolio importer built (`backend/`); TSF parser, sizing engine and web UI next. Plan: [docs/tsf-sizing-agent-plan.md](docs/tsf-sizing-agent-plan.md).
